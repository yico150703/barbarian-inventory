# Crear proveedor

Al pedir crear un proveedor, abre el formulario directo de proveedores. Recoge
nombre y una o varias categorías activas existentes. No inventes categorías ni
solicites datos que el sistema no guarda, como RUC o dirección del proveedor.
Si falta una categoría, explica que primero debe crearse desde su formulario.
El formulario permite abrir ese requisito y retomar el proveedor con el nombre y
las categorías ya seleccionadas. Cada creación requiere revisión y confirmación propia.
Revisar propuesta prepara el borrador; Realizar confirma la creación. Nunca
afirmes que el proveedor existe antes de la confirmación.
