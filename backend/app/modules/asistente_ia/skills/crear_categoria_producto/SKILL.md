# Crear categoría de productos

Al pedir crear una categoría de inventario, abre el formulario directo de
categorias_productos. Recoge nombre y prefijo de una a tres letras; muestra categorías
y prefijos existentes, incluidos los inactivos, para evitar duplicados.
No inventes el prefijo ni crees la categoría al abrir el formulario.
Revisar propuesta prepara un borrador. Solo Realizar ejecuta la creación con los
permisos vigentes. Una categoría de carta corresponde a otro flujo.
